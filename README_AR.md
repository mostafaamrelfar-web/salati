# مشروع صَلَاتِي – Android (Kotlin)

هذا مشروع أندرويد أولي قابل للبناء والتطوير، وليس APK جاهزاً بعد.

## ما يحتويه الإصدار الأول
- واجهة عربية بسيطة.
- طلب إذن الموقع وجلب مواقيت اليوم من AlAdhan API (طريقة حساب Muslim World League).
- جدولة إشعار قبل كل صلاة بخمس دقائق، وإشعار عند دخول الوقت.
- تفعيل مدة وضع الصلاة لمدة 15 دقيقة عند الأذان.
- اختيار YouTube وTikTok وInstagram وFacebook للحظر.
- خدمة Accessibility اختيارية لاعتراض فتح التطبيقات المحددة أثناء وضع الصلاة.
- زر خروج للطوارئ ينهي وضع الصلاة.

## متطلبات البناء
- Android Studio حديث.
- JDK 17.
- Android SDK 35.
- Gradle 8.9 مع Android Gradle Plugin 8.7.3.

افتح مجلد المشروع في Android Studio ثم شغّل Gradle Sync وبعدها Build > Build APK(s).

## تنبيهات مهمة قبل الاستخدام
1. هذا نموذج أولي يحتاج اختباراً على جهاز فعلي، ولا أضمن دقة التنبيهات أو عملها في كل إعدادات توفير الطاقة.
2. عند أول تشغيل: اسمح بإذن الموقع والإشعارات، ثم اضغط "تحديد موقعي وتحديث المواقيت".
3. يجب تحديث المواقيت بعد منتصف الليل أو عند السفر؛ الإصدار الأول يجدول صلوات اليوم الحالي فقط.
4. اختيار طريقة الحساب حالياً مضبوط على Muslim World League (method=3). يمكن تطوير اختيار طريقة الحساب حسب البلد.
5. حظر التطبيقات يتطلب تفعيل خدمة "حظر التطبيقات وقت الصلاة" يدوياً من إعدادات إمكانية الوصول. هذه الخدمة حساسة؛ راجع صلاحياتها ولا تفعلها إلا إذا كنت تريد هذه الوظيفة.
6. بعض إصدارات Android/Honor قد تؤخر المنبهات بسبب توفير البطارية. قد تحتاج إلى السماح للتطبيق بالعمل في الخلفية.
7. لا يحاول التطبيق قفل الهاتف بالكامل؛ بل يعرض شاشة تذكير فوق التطبيقات المختارة فقط. زر الطوارئ ينهي وضع الحظر.

## ملاحظات التطوير
- إضافة تحديث تلقائي يومي للمواقيت وإعادة الجدولة بعد إعادة تشغيل الهاتف.
- إضافة اختيار طريقة الحساب والمذهب للعصر.
- إضافة قائمة تطبيقات ديناميكية بدلاً من قائمة التطبيقات الافتراضية.
- تحسين آلية الحصول على موقع حديث باستخدام Fused Location Provider.
- إضافة مصدر موثوق ومراجع للآيات مع اختبار النصوص.


## صوت الأذان المرفق
- أُضيف ملف `app/src/main/res/raw/adhan.mp3` مستخرجاً من الفيديو الذي أرسله المستخدم (صوت فقط، نحو 4:03 دقائق).
- إشعار دخول وقت الصلاة يستخدم قناة إشعارات مستقلة بصوت الأذان المرفق؛ تذكير ما قبل الصلاة يبقى منفصلاً.
- في أندرويد 8 فأحدث، إعداد صوت قناة الإشعار قد يُحفظ من أول إنشاء للقناة. إذا كانت القناة قد أُنشئت سابقاً، احذف التطبيق/بياناته أو غيّر إعداد القناة من إعدادات الإشعارات لاختبار الصوت.
- تشغيل صوت الإشعار يتأثر بوضع الصامت وعدم الإزعاج ومستوى صوت الإشعارات وسياسات الجهاز.
